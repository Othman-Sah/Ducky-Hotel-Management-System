# Project Report: Hotel Management System

This document provides a detailed analysis of the C++ Hotel Management System project. Each file is examined to document its purpose, and each function is described with its role and location.

## File: main.cpp

This is the main entry point of the application. It initializes the system, sets up initial data, and runs the main event loop.

### Functions:

- **`int main()`**
  - **Location:** `main.cpp`, line 12
  - **Description:**
    - Initializes the retro-style console UI.
    - Creates instances of the `Authentication` and `Hotel` classes.
    - Initializes the `Restaurant` menu and the `ParkingManager` with a set number of spots.
    - Populates the hotel with a predefined set of rooms of different types and prices.
    - Loads any existing reservations from storage.
    - Enters the main application loop, which presents the user with three options:
      1.  **LOGIN:** Initiates the login sequence. If successful, it directs the user to either the Admin or User dashboard based on their role.
      2.  **HOTEL MAPS:** Gathers data about rooms, parking, and restaurant tables and displays a visual map of the hotel facilities.
      3.  **EXIT SYSTEM:** Terminates the application.
